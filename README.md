# FIELDNOTE

Русскоязычное приложение для бизнес-планирования: финмодель, каналы, наблюдения за рынком, контент-план и задачи команды, план-факт, эксперименты и ИИ-анализ. Дополнительный модуль «Партии и остатки» считает полную стоимость поставки, вложения в складской остаток и ориентир повторного заказа.

## Запуск

Требуется Node.js 22.12 или новее.

```bash
npm install
cp .env.example .env
npm run dev
```

Приложение откроется на Vite-адресе в терминале; сервер API запускается на порту 3001. Для ИИ укажите `OPENAI_API_KEY` в `.env`. Ключ хранится только на сервере. Без ключа модель, расчёты и остальные функции продолжают работать, а ИИ-помощник покажет понятное сообщение.

## Production

```bash
npm run build
npm start
```

Express раздаёт `dist` и обслуживает API. Для публичного развёртывания нужен Node-хостинг с переменной окружения `OPENAI_API_KEY`; статический GitHub Pages не может запустить серверный ИИ. Данные приложения сохраняются в `localStorage` браузера и могут быть экспортированы/импортированы в JSON. Они не синхронизируются между устройствами.

## Данные и расчёты

Исходные значения перепродажи взяты из предоставленного `dashboard.html`. Пустые поля конкурентного анализа и остатков не заполнены выдуманными цифрами. Прогнозная маржа рассчитывается после налога; плановая прибыль учитывает OPEX, который в исходной модели уже включает ежемесячные расходы. ИИ получает бизнес-контекст только после нажатия кнопки анализа.
